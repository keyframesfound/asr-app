# ASR Lesson Tool — Implementation Plan

A local web app: upload MP3 → local Whisper transcription → transcript shown at the bottom → two buttons: **AI Summary** (OpenRouter) and **Generate Google Form Quiz** (via paste-in Apps Script, no Google Cloud setup).

## Stack & Key Decisions

- **Backend: Python 3.12 + FastAPI**, one server serving both the page (static files) and the API. Python is the natural fit for Whisper, and everything stays on `127.0.0.1:8000` — your OpenRouter key never leaves the server.
- **Transcription: whisper.cpp via Homebrew** (`brew install whisper-cpp`) with the **large-v3-turbo** GGML model. Cantonese is Whisper's weak spot — small/base models butcher it, but large-v3-turbo supports Cantonese (`yue`) + English at ~6× the speed of large-v3, and runs Metal GPU-accelerated on your Mac. ffmpeg (already installed) converts MP3 → 16 kHz mono WAV first. Language: auto-detect by default, with a dropdown to force Cantonese/English/Mandarin.
- **AI: OpenRouter, server-side key in `.env`.** Default model `deepseek/deepseek-chat` (DeepSeek's main cheap chat line, ~$0.14–0.27/M input — a full 1-hour transcript ≈ 15k tokens fits in one call and costs a few HK cents). Model is a `.env` setting with free fallbacks documented (Qwen/GLM Flash free tiers). No chunking needed.
- **Quiz → Google Form via Apps Script paste-in:** the LLM returns strict JSON (10 MCQs: question, 4 options, correct answer, explanation, in the chosen language); the server renders a complete standalone `Code.gs` with the quiz embedded. The page shows the script + a **Copy** button + numbered steps (script.google.com → paste → Run → authorize → copy the form URL from the log). The script itself creates a quiz-mode form (correct answers marked, explanations shown after submission) and logs + emails the form URL to the teacher.
- **Output language selector:** 繁體中文（香港）/ 简体中文 / English — applied to both summary and quiz.

## Page Layout

Single page, no build step:
1. **Upload zone** — drag & drop / file picker, MP3 (+ WAV/M4A accepted via ffmpeg).
2. **Progress** — transcription progress bar (parsed from whisper.cpp output, polled every second).
3. **Transcript** (bottom section) — rendered with timestamps, stored to `transcripts/`.
4. **Controls** — language dropdown + the two buttons: **AI Summary** and **Generate Quiz Form**. Summary renders below the transcript; the quiz section shows the generated Apps Script with copy button and step-by-step instructions.

## Project Structure

```
asr-web/
├── .env.example            # OPENROUTER_API_KEY, OPENROUTER_MODEL, whisper settings
├── .gitignore              # .env, uploads/, transcripts/, models/, __pycache__
├── requirements.txt        # fastapi, uvicorn[standard], python-multipart, httpx, python-dotenv
├── README.md               # full setup + daily-use instructions
├── scripts/download_model.sh  # curl large-v3-turbo GGML → models/
├── appscript/quiz_template.js # Apps Script template with quiz placeholder
├── static/                 # index.html, app.js, style.css
└── app/
    ├── main.py             # FastAPI routes
    ├── transcribe.py       # ffmpeg convert + whisper.cpp subprocess + progress parsing
    ├── llm.py              # OpenRouter calls (summary prompt, quiz JSON prompt + validation)
    └── forms.py            # quiz JSON → Apps Script source generation
```

**API routes:** `POST /api/upload` (saves file, starts background transcription job, returns job id) · `GET /api/jobs/{id}` (status + progress + transcript when done) · `POST /api/summary` · `POST /api/quiz` (returns generated Apps Script text). Simple polling — no SSE complexity.

## What YOU need to do (one-time setup, ~10 min)

1. `brew install whisper-cpp` (I can run this for you)
2. Run `scripts/download_model.sh` — downloads the ~1.6 GB turbo model once into `models/`
3. `pip3 install -r requirements.txt`
4. `cp .env.example .env` and paste your OpenRouter API key into it
5. Start with `uvicorn app.main:app` and open `http://127.0.0.1:8000`

No Google Cloud project is needed — quizzes go through the Apps Script paste-in flow.
