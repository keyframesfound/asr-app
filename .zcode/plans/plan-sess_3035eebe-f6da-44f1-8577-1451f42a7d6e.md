# Replace Apps Script generation with direct Google Forms API

**No SSO or login system is built.** Your already-registered OAuth client (redirect URI `http://127.0.0.1:8000/`) is used as-is — no further Google Cloud console edits. The one-time sign-in popup is Google's own consent page; the token is stored locally (`google_token.json`) and refreshed automatically afterwards. Note: the URI must match your registration exactly, so the app will serve on 127.0.0.1:8000 (its current default) when using this feature.

## New flow

1. Click **📝 Generate Google Form Quiz** → `POST /api/quiz` (unchanged LLM call) returns the questions JSON instead of a script.
2. Frontend calls the new `POST /api/forms` with `{title, description, questions}`.
3. **First time only**: no stored token → backend returns `401 {auth_url}`; frontend opens the Google consent popup with `redirect_uri=http://127.0.0.1:8000/`. Google redirects the popup back to the app root with `?code=...&state=...`; `GET /` detects those params (or `error=` for a declined consent), exchanges the code, saves the token, and returns a tiny HTML page that messages the opener and closes itself; the frontend retries `POST /api/forms` automatically — links appear with no further clicks. Otherwise `GET /` serves index.html exactly as before.
4. **Every other time**: one click. Backend calls `forms.create`, then two `batchUpdate`s: (a) description + `quizSettings.isQuiz=true` + `emailCollectionType=DO_NOT_COLLECT`; (b) one `createItem` per question — RADIO, required, 1 point, correct answer by option text, `whenWrong` feedback = explanation. Returns `{form_url (responderUri), edit_url, count}`.

## File changes

- **`app/forms.py`** — rewrite: Forms API client using plain `httpx` (already a dependency, no new packages). Functions: `is_configured()`, `build_auth_url(state)`, `exchange_code(code)`, `access_token()` (refresh when expired), `create_quiz_form(...)`. Constants: `REDIRECT_URI = os.environ.get("GOOGLE_REDIRECT_URI", "http://127.0.0.1:8000/")`, scope `https://www.googleapis.com/auth/forms.body`. Token persisted in `google_token.json`.
- **`app/main.py`** — `/api/quiz` returns `{title, description, questions, count}`; new `POST /api/forms` (401 + `auth_url` when unauthenticated; 400 with setup instructions when client ID/secret missing); existing `GET /` branches: if `code`/`state`/`error` query params present → OAuth callback handling (validate in-memory `state`, exchange code, save token, self-closing HTML), else serve index.html.
- **`static/index.html`** — quiz card becomes a result card: "Open quiz form" (student link), "Edit form" (teacher link), copy-link button; remove the paste-in steps and script block.
- **`static/app.js`** — button handler: `/api/quiz` → `/api/forms`; on 401 open popup (fallback link if blocked), stash payload, retry on `oauth-done` message; on cancelled sign-in show Retry that reuses the stashed questions (no second LLM call).
- **`.env.example`** — add `GOOGLE_CLIENT_ID=`, `GOOGLE_CLIENT_SECRET=`; **`.gitignore`** — add `google_token.json`; **`README.md`** — brief setup note (client ID/secret in `.env`, redirect URI must exactly match the registered `http://127.0.0.1:8000/`).

## Known differences vs Apps Script version

- No question-order shuffle (REST API has no equivalent of `setShuffleQuestions`); everything else replicated.
- Form lands in the user's Drive root; responder link shareable as before.

## Verification

Run the app, do the one-time consent, generate a quiz, and check the form: quiz mode on, N required multiple-choice questions at 1 point, correct answer marked, explanation shown on wrong answers, both links working.
