# Darken unselected segments in the summary-length picker

## Problem
The Brief / Standard / In-depth picker (`SettingsView.swift:29`) is a stock SwiftUI `.pickerStyle(.segmented)` control, so its segment backgrounds are native macOS greys — the selected segment is barely lighter than the unselected ones. SwiftUI doesn't expose segment background colors, so the fix is a small custom segmented control styled with the app's existing Hex palette.

## Changes

### 1. `macapp/Sources/LessonTranscriber/Views/Components.swift`
- Add two palette constants to the `Color` extension (lines 96–114):
  - `hexSegmentTrack` — dark inset well for the control, `#101010` (same as `hexBackground`, clearly darker than the `#171717` card it sits on)
  - `hexSegmentSelected` — selected-segment fill, `Color.white.opacity(0.16)` (≈ #363636, close to the current native selected grey, so the selected segment keeps its look while unselected ones get much darker)
- Add a `HexSegmentedPicker<Option: Hashable & Identifiable>` view (near the button styles):
  - Rounded track (cornerRadius 7, `hexSegmentTrack` fill, `hexBorder` hairline) containing an HStack of segment buttons
  - Selected segment: `hexSegmentSelected` fill, white `.medium` label, sliding highlight animated with `matchedGeometryEffect`
  - Unselected segments: `hexSidebarText` (#A6A6A6) labels, 1 pt divider between adjacent unselected segments (like the native control), hover lightens the fill slightly
  - Accessibility: `.isSelected` trait on the selected segment
- Signature: `init(selection: Binding<Option>, options: [Option], label: KeyPath<Option, String>)` — reusable but only this one call site needs it.

### 2. `macapp/Sources/LessonTranscriber/Views/SettingsView.swift`
- Replace the stock `Picker` (lines 29–36) with:
  ```swift
  HexSegmentedPicker(
      selection: $settings.summaryLength,
      options: SummaryLength.allCases,
      label: \.label)
      .frame(width: 300)
  ```
- Same width/position, binding unchanged, so the subtitle blurb still updates.

## Verification
1. `DEVELOPER_DIR=/Applications/Xcode.app swift build` in `macapp/` (per project memory, plain CLT fails on SwiftUI macros).
2. Launch the app and check the Settings pane: unselected segments clearly darker than the selected one; clicking each segment moves the highlight; hover feedback works.
3. Exact grey values are isolated in the two new constants — trivially tweakable if you want more/less contrast after seeing it.
